# 第八阶段：音乐、时钟、天气、信箱、礼物、塔罗

所有应用继承 Winter Letter 主题与三屏桌面；数据保存在本机 IndexedDB（每个应用只新增自己的表）。

## 音乐（PR A）

- 从 iPhone「文件」导入**你自己拥有**的音频（MP3、M4A、AAC、WAV 等浏览器支持的格式）；单个文件最多 80 MB，一次最多 30 首；聆聆不下载、不抓取、不提供任何音乐
- 本机读取 MP3 的 ID3 标签（标题、歌手、专辑、封面）；没有标签时从文件名「歌手 - 标题」识别
- 播放 / 暂停、上一首 / 下一首、拖动进度、音量（iPhone 上网页不能调节音量，如实提示用侧边音量键）、列表循环 / 单曲循环、随机播放
- 收藏、歌单（新建、重命名、添加、移出、调整顺序、删除歌单不删歌曲）、搜索
- 睡眠定时：15 / 30 / 45 / 60 分钟后暂停，或播完这首后停止
- 全局只有一个播放器：离开音乐页面继续播放；桌面音乐小组件显示同一个状态（正在播放 / 暂停 / 进度）
- 刷新后恢复上次的队列与位置（暂停状态，不会自动出声）
- 锁屏 / 控制中心的播放控制（Media Session，浏览器支持时）
- 删除歌曲同时删除本机音频文件并从所有歌单移除；iPhone「文件」中的原文件不受影响
- 存储超过 80% 时提醒
- 数据：Dexie v11 新增 `tracks` `trackBlobs` `playlists`（备份在 PR G 中加入）

**已知 iOS 限制**：Safari 在锁屏或切到其他 App 后可能暂停网页播放（主屏幕 App 更明显）；第一次播放必须由点按触发。

**真机待测**：M1 从「文件」导入 MP3 / M4A；M2 锁屏后是否继续播放、锁屏控制是否可用；M3 带封面的 MP3 是否显示封面；M4 大文件（50 MB）导入速度与存储提示。

## 时钟（PR B）

- **时钟**：实时时间（含秒）、中英文日期；**世界时钟** 21 个城市可选，添加 / 移除 / 排序，显示日期差与时差（浏览器内置时区数据，不联网）
- **秒表**：开始 / 暂停 / 继续 / 计次 / 复位；按时间点计算，切换页面和刷新后仍准确
- **倒计时**：自定义名称、分秒输入与常用预设，多个同时进行，暂停 / 继续 / 取消；**记录**（结束、在离开期间结束、已取消），可清空
- 桌面时间小组件：点按进入时钟；有进行中的倒计时时显示「名称 · 几点结束」
- 数据：Dexie v12 新增 `timers`；世界时钟与秒表存在设置中

### 提醒能力（页面中如实说明）
| 情况 | 能做到 |
| --- | --- |
| 聆聆在前台 | 任何页面弹出「计时结束」，响铃（需要先点过一次开始，iPhone 才允许出声；iPhone 不支持网页震动） |
| 锁屏 / 切到其他 App | Safari 暂停网页，**不会响铃**；回来后提示「在你离开期间（几点）结束，没有响铃」，记录中也这样标注 |
| 关闭网页 | 不会提醒 |
| 需要可靠提醒 | 「同时在 iPhone 提醒事项中提醒我」→ 第七阶段的快捷指令，创建真正的系统提醒（运行状态如实显示） |

**真机待测**：K1 前台计时结束是否响铃；K2 锁屏期间结束、解锁回来后的提示；K3「同时在 iPhone 提醒事项中提醒我」创建的提醒时间是否正确。

## 天气（PR C）

- 数据来源 **Open-Meteo**（https://open-meteo.com）：免费、不需要账号或 API Key
  - 条款：仅限非商业使用；每天约 10,000 次请求以内；数据按 CC BY 4.0 需要署名（页面显示「数据来源 Open-Meteo」）
  - 隐私：只发送你输入的**城市名称**（搜索）或所选城市的**经纬度**（预报）；Open-Meteo 服务器会看到你的 IP。**不使用定位**
  - 第一次联网前需要你点「同意并继续」；可以随时「撤回联网同意」
- 搜索城市（中文结果）、收藏最多 12 个城市、手动切换、移除
- 当前天气（温度、体感、湿度、天气、风向风速、降水）与 7 天预报（最高 / 最低温、降水概率）
- 显示更新时间与数据来源；30 分钟内用缓存，「刷新」强制更新
- **失败时如实显示错误**（网络、配额用完、服务器错误）；有上次成功的数据时注明「几点的旧数据，可能已经过时」；没有数据时不显示任何天气
- 桌面天气小组件（新增）：所选城市的温度与天气；未设置时显示「点按设置城市」；点按进入天气
- 桌面布局 v3：已有用户的布局只**加入**天气小组件（放得下的位置），其他应用、小组件、Dock 都不变；删掉后不会再加回来
- 数据存在设置中（城市、缓存、同意状态），无数据库表变化

开发环境实测：城市搜索可用；预报接口因为开发环境的公共出口 IP 当天配额已用完而返回「Daily API request limit exceeded」，页面如实显示「免费请求次数已用完」——这正是失败处理的真实例子。在你自己的 iPhone 上使用的是你自己的网络与配额。

**真机待测**：W1 搜索并添加城市；W2 天气与预报显示；W3 桌面天气小组件。

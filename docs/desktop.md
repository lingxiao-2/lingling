# 虚拟手机桌面（V1 第四阶段）

## PR A：三屏桌面基础

- **首页就是桌面**：三个桌面页，左右滑动切换。使用原生滚动加 scroll-snap，一次只翻一页；页面指示点也可以点。
- **固定 Dock**：消息、联系人、动态、我的。Dock 不在滑动区域里，始终固定。「消息」显示未读角标。
- **图标**：每页 4 列 × 6 行。图标 60 px，圆角约 23.5%，半透明珍珠白底、白色内描边、1.5 px 细线图标，名称 11 px。
- **打开与返回**：点图标进入原有页面。浏览器返回即回到桌面，并停在原来那一页（本次会话内记住页码，PR B 起永久保存）。原来四个页面的底部导航多了一个「桌面」。
- **待开发应用**：相册、日记、便签、日历、音乐、时钟、天气、信箱、礼物、塔罗，进入如实说明的待开发页，不伪造数据，也没有假按钮。图标右下角有一个小灰点表示还没开发。
- **新的「记忆」应用**：按角色进入各自的长期记忆。

## PR B：编辑与保存

- **长按进入编辑模式**：按住图标约 0.5 秒。手指移动超过 10 px 视为滑动翻页，不会进入编辑；进入编辑的那一次按压不会打开应用。
- **编辑模式**：图标轻微晃动（系统开启「减弱动态效果」时不晃动）。点按图标不会打开应用，右上角「完成」退出。
- **拖动**：
  - 按住图标拖到另一个图标的位置，插到那里；拖到空白处，放到这一页最后
  - 拖到屏幕左右边缘停留约 0.5 秒，翻到相邻页，再放下即可跨屏移动
  - 拖进 Dock：有空位直接放入；Dock 已满（4 个）时，与目标位置的应用互换
  - 目标页放不下时不移动
- **保存**：
  - 布局、Dock、顺序和当前页码保存在 IndexedDB `settings` 表中独立的一项 `desktop-layout`，带版本号，**没有修改数据库结构**
  - 第一次进入桌面时生成默认布局，之后不会再用默认布局覆盖你的自定义布局
  - 读到的数据先修复再用：损坏时退回默认，新版本新增的应用会补到有空位的页
- **恢复默认**：桌面编辑模式左上角，或「主题装扮 → 桌面 → 恢复默认桌面布局」。只重置桌面这一项，不影响角色、聊天、动态、记忆。

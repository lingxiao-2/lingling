# 动态 / 朋友圈（V1 第三阶段）

## PR A：用户动态

入口：底部导航「动态」，右上角相机按钮发动态。

| 功能 | 说明 |
|---|---|
| 发布 | 正文最多 2000 字，最多 9 张配图；未发布的正文自动保存为草稿（只在本机） |
| 配图 | 只能从本机选择；在本机缩小到最长边 1280 px、转成 JPEG（单张约 900 KB 以内），不上传任何服务器；只接受本机图片 dataURL，拒绝网址和 SVG |
| 可见范围 | 所有角色 / 部分角色（勾选）/ 仅自己。只决定哪些角色能看到和互动（PR B）；动态始终只保存在本机 |
| 查看 | 列表新的在上；九宫格配图，点开看大图，左右点切换 |
| 点赞 | 可以取消，同一人只算一次 |
| 评论 | 可以评论，点别人的评论可以回复；点自己的评论即删除，底部可撤销 |
| 删除 | **软删除**：从列表隐藏，底部 6 秒内可撤销；数据不会被真正删除 |
| 备份 | `moments` 表本来就在备份里，配图、点赞、评论、可见范围随动态一起备份和恢复 |

**数据库**：沿用 v1 就有的 `moments` 表，新增字段（`visibleTo`、`likes`、`comments`、`deleted`、`updatedAt`）都是可选的，**没有升级数据库版本，也没有迁移**；旧数据原样可用。

**测试**：`scripts/test-moments.ts`（发布校验、可见范围、时间显示、点赞评论、软删除与撤销、旧数据兼容、备份往返）。

### iPhone 验收
| # | 操作 | 预期 |
|---|---|---|
| A1 | 动态 → 相机 → 写字、从相册选 3 张图 → 发表 | 列表最上面出现，三张图九宫格显示，点开能左右切换 |
| A2 | 写一半返回，再进入发动态 | 刚才的文字还在 |
| A3 | 发一条「仅自己」、一条「部分角色」 | 动态下显示锁和可见范围 |
| A4 | 点赞再取消；评论；点自己的评论 | 点赞状态正确；评论出现；点自己的评论后消失，底部出现「撤销」可以恢复 |
| A5 | 删除一条动态 → 点「撤销」 | 动态连同图片、点赞、评论完整回来 |
| A6 | 我的 → 备份 → 导出后恢复 | 动态和配图都在 |

## PR B：角色动态

每一次模型请求都由用户的操作触发，**不会在后台定时自动请求**。只有在角色资料页开启「参与朋友圈」（`permissions.postMoments`，旧角色默认开启）的角色才会参与。

| 功能 | 触发 | 请求次数 |
|---|---|---|
| 让角色发一条动态 | 动态页右上角人像按钮 → 选择角色 | 1 次 |
| 请角色来看你的动态 | 发动态时勾选（最多 3 个，只列出能看到这条动态的角色） | 每个角色 1 次 |
| 角色回复你的评论 | 在角色的动态下评论，或回复某个角色的评论 | 1 次 |

**依据与诚实**
- 角色只读取自己的人设、与你的关系、你确认过的记忆（同一套本地检索）和你们最近 12 条真实聊天；不读取其他角色的任何内容。
- 提示词明确要求：不编造你们没有真实发生过的共同经历；角色不能发图片；看不到你的配图时如实说明，不描述画面。
- 评论区里，角色只看到你和它自己的评论，看不到其他角色的评论。
- 「仅自己可见」的动态不会交给任何角色；「部分角色可见」只交给选中的角色。
- 模型返回格式不对时不点赞、不评论，也不编造结果；空内容不发布。

**测试**：`scripts/test-moments-ai.ts`（模拟模型）——输出清理与解析、配图说明、评论隔离、回复对象、发动态的上下文与隔离、权限关闭不请求、可见范围与最多 3 个、失败不编造、仅自己可见不请求、评论回复。

**未验证**：真实模型（如 DeepSeek）的文笔和是否稳定按 JSON 返回，需要真机验收：

| # | 操作 | 预期 |
|---|---|---|
| B1 | 动态页 → 人像按钮 → 选一个角色 | 几秒后出现一条符合 TA 性格的动态，没有编造你们没做过的事 |
| B2 | 在 TA 的动态下评论 | TA 回复你一句 |
| B3 | 发一条带图的动态，勾选请 TA 来看看 | TA 按性格决定点不点赞、评不评论；不会描述图片内容 |
| B4 | 发一条「仅自己可见」 | 没有「请角色来看看」选项 |
| B5 | 角色资料页关闭「参与朋友圈」 | 这个角色不再出现在可选列表中 |

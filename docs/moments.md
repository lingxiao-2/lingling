# 动态 / 朋友圈（V1 第三阶段）

## PR A：用户动态

入口：底部导航「动态」，右上角相机按钮发动态。

| 功能 | 说明 |
|---|---|
| 发布 | 正文最多 2000 字，最多 9 张配图；未发布的正文自动保存为草稿（只在本机） |
| 配图 | 只能从本机选择；在本机缩小到最长边 1280 px、转成 JPEG（单张约 900 KB 以内），不上传任何服务器；只接受本机图片 dataURL，拒绝网址和 SVG |
| 可见范围 | 所有角色 / 部分角色（勾选）/ 仅自己。只决定哪些角色能看到和互动（PR B）；动态始终只保存在本机 |
| 查看 | 列表新的在上；九宫格配图，点开看大图，左右点切换 |
| 点赞 | 可以取消，同一人只算一次 |
| 评论 | 可以评论，点别人的评论可以回复；点自己的评论即删除，底部可撤销 |
| 删除 | **软删除**：从列表隐藏，底部 6 秒内可撤销；数据不会被真正删除 |
| 备份 | `moments` 表本来就在备份里，配图、点赞、评论、可见范围随动态一起备份和恢复 |

**数据库**：沿用 v1 就有的 `moments` 表，新增字段（`visibleTo`、`likes`、`comments`、`deleted`、`updatedAt`）都是可选的，**没有升级数据库版本，也没有迁移**；旧数据原样可用。

**测试**：`scripts/test-moments.ts`（发布校验、可见范围、时间显示、点赞评论、软删除与撤销、旧数据兼容、备份往返）。

### iPhone 验收
| # | 操作 | 预期 |
|---|---|---|
| A1 | 动态 → 相机 → 写字、从相册选 3 张图 → 发表 | 列表最上面出现，三张图九宫格显示，点开能左右切换 |
| A2 | 写一半返回，再进入发动态 | 刚才的文字还在 |
| A3 | 发一条「仅自己」、一条「部分角色」 | 动态下显示锁和可见范围 |
| A4 | 点赞再取消；评论；点自己的评论 | 点赞状态正确；评论出现；点自己的评论后消失，底部出现「撤销」可以恢复 |
| A5 | 删除一条动态 → 点「撤销」 | 动态连同图片、点赞、评论完整回来 |
| A6 | 我的 → 备份 → 导出后恢复 | 动态和配图都在 |

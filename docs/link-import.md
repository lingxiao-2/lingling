# 表情包：通过链接导入

## 现在的做法：浏览器直接读取
- 聆聆是纯前端应用，链接由**你的浏览器直接请求**，不经过任何聆聆服务器或第三方代理。
- 请求不带登录状态（`credentials: omit`），也不带来源信息（`no-referrer`）。
- 文件类型按内容判断：先看文件头是否为 PNG / JPEG / WebP / GIF，再看是否为 ZIP，最后看是否为 HTML 网页。不看扩展名，也不看 Content-Type。
- 限制：

  | 项目 | 上限 |
  |---|---|
  | 单张图片 | 5 MB |
  | ZIP | 60 MB |
  | 网页 | 3 MB |
  | 超时 | 20 秒 |
  | 跳转 | 跟随，但跳转后的地址要重新校验 |

  下载时边读边计数，超过上限立即停止。ZIP 解压沿用本地导入的上限：最多 600 个文件、总大小 200 MB、压缩比不超过 60。
- 拒绝的地址：本机、内网、链路本地、云元数据（如 169.254.169.254）、`.local` / `.internal` 域名、带用户名或密码的链接、非 http / https 协议。
- 网页提取（尽力而为）：
  - 只看 `<main>` 或 `<article>`；都没有时看 `<body>`，并去掉页头、页脚、导航和侧栏。
  - 图片地址读取 `src`、`data-src`、`data-original`，以及 `srcset` 中最大的一张。
  - 也读取指向图片或 ZIP 的 `<a>` 链接。
  - 过滤头像、logo、图标、广告、二维码、小于 48px 的图、SVG 和 data: 地址。
  - 用户在预览中自己勾选要导入哪些。
  - 用脚本动态加载图片的页面，通常识别不到。

## 浏览器做不到的
浏览器只能读取**允许跨域读取（CORS）**的资源。很多网站、图床和社交平台都不允许，这时会提示：

> 这个网站不允许其他网站直接读取它的文件（跨域限制），或者网络无法连接。可以先把图片保存到相册或「文件」，再从那里导入。

需要登录（401 / 403）、文件不存在（404）、访问过于频繁（429）也会分别提示原因。聆聆不会绕过登录、付费墙或平台限制，**也不会使用公共 CORS 代理**：这类代理会看到你的链接和图片。

## 以后如果需要：受控代理（只有设计，未部署）
如果确实需要导入不允许跨域的公开图片，可以部署一个**只属于你自己**的代理，例如 Cloudflare Worker。必须满足：

1. **访问控制**：只接受来自聆聆域名的请求，并带访问口令；按 IP 和口令限流。
2. **防止 SSRF**：
   - 只允许 http / https 协议，以及 80 / 443 端口。
   - 先解析 DNS，拒绝私有、本机、链路本地、CGNAT、组播、IPv6 唯一本地和 IPv4 映射地址，以及云元数据地址。
   - 每次跳转都重新解析、重新校验；最多跳转 3 次。
3. **限制下载**：
   - 只放行 `image/*`、`application/zip`、`text/html` 三类内容。
   - 按文件头再确认一次类型。
   - 大小上限与浏览器端相同；超时 15 秒。
4. **请求本身**：
   - 不转发 Cookie 和 Authorization 头。
   - 不缓存用户链接，日志里不记录完整 URL。
5. **遵守规则**：遵守目标网站的 robots 规则和访问条款；对需要登录的资源一律拒绝。

部署这个代理可能产生费用，需要你确认后才会进行。目前代码里**没有**调用任何代理。

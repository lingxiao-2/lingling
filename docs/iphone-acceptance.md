# iPhone 真机验收清单

这份清单写给只有 iPhone 的使用者：每一项都可以在 Safari 里完成，不需要电脑。

开发环境无法连接真实 iPhone，也没有你的 DeepSeek Key。下面所有项目在你实际测过之前，都应视为**未验证**。

## 0. 准备
- 打开 https://lingxiao-2.github.io/lingling/ ，先在 **我 → 备份与恢复** 导出一份全部数据备份，保存到「文件」。
- 后面的测试都不会删除数据。即使出了问题，也可以用这份备份恢复。

## 1. 真实 DeepSeek 聊天（P0）
| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 我 → AI 服务 → 自己的 API，填 `https://api.deepseek.com/v1`、你的 Key、模型 `deepseek-chat`，点「测试连接」 | 显示连接成功。Key 只保存在这台手机里，聆聆不会上传 |
| 1.2 | 和一个角色发一句「早上好」 | 回复 1～5 条气泡，语气符合人设 |
| 1.3 | 回复过程中点「停止」 | 停在已经收到的部分，没有报错 |
| 1.4 | 长按最后一条回复 →「重新生成」 | 换一组新的回复，旧回复不会重复出现 |
| 1.5 | 打开飞行模式后发送 | 提示网络错误；关闭飞行模式后可以重试 |
| 1.6 | 角色资料页「你们的关系」设为恋人，再聊 | 不像初次见面，不重新表白，不频繁叫「宝宝」 |
| 1.7 | 世界书条目的关键词出现在聊天中 | 回复中用到这个条目的设定 |
| 1.8 | 角色资料页 →「资料整理」→ 同意并用 AI 整理 | 显示整理结果；如果失败，原资料不变。**请截图告诉我结果**：这一步能验证 DeepSeek 是否稳定输出 JSON |

## 3. iPhone 体验
- **刷新与切换**：聊天中下拉刷新，或切到别的 App 再回来，聊天记录和草稿都还在。
- **输入法**：中文输入法联想、换行、发送都正常；键盘弹出时输入框不被挡住。
- **长聊天**：几百条消息时滚动流畅，点「回到底部」正常。
- **导入**：从「文件」导入 DOCX 角色、相册多选图片、ZIP，都能完成。
- **存储空间**：我 → 表情包与识图 → 存储，能看到已用空间。
- **添加到主屏幕**：Safari 分享 → 添加到主屏幕。从主屏幕打开时没有地址栏，刘海和底部横条区域不遮挡内容。
- **版本更新**：发布新版本后，关掉页面重新打开（或下拉刷新）能看到新功能。

  已知限制：目前没有离线缓存（Service Worker）。断网时打不开页面，但已经保存的数据不会丢。

## 4. 表情包
- 批量文本导入：粘贴 `scripts/fixtures/stickers/batch-sample.txt` 中的 31 行，记录成功、重复、失败各多少，以及失败原因的截图。
- 如果失败原因显示「跨域限制」，说明 i.imgant.com 不允许网页直接读取图片。这时可以长按图片存到相册后再导入，或者按 `docs/link-import.md` 自己部署图片代理（免费额度内不花钱；部署前请先读费用说明）。

## 5. 自然聊天与关系连续性（V1 第二阶段 PR A）
自动测试只用了模拟模型，**下面这些需要用真实模型（例如 DeepSeek）在 iPhone 上验收**：

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | 导入一个写明「你是他的女朋友」的角色，第一句发「在干嘛」 | 第一句就像恋人那样接话，不自我介绍、不问「你是谁」、不问要不要交往 |
| 5.2 | 同一角色连续聊 50 轮以上（日常、吐槽、认真问题混着聊） | 性格不漂移：寡言的一直话少，活泼的一直活泼；不会越聊越像客服 |
| 5.3 | 只发「哈哈」「嗯」这类短句 | 回复也短，通常一两条，不长篇大论、不总结、不反问 |
| 5.4 | 认真问一个问题（比如「这个报错怎么办」） | 回复可以变长，把事情讲清楚 |
| 5.5 | 说「今天好累」 | 先回应情绪，不立刻给一堆建议，不用「我理解你的感受」这种套话 |
| 5.6 | 留意几轮回复 | 不每句都叫「宝宝」，不每次都以提问结尾，不每条都带 emoji，开头不总是同一个词 |
| 5.7 | 角色资料页把关系从「恋人」改成「已婚」，回到聊天发一句 | 下一条回复就按伴侣相处，不解释、不再提「交往」 |
| 5.8 | 角色资料页 →「查看发送给 AI 的设定」 | 能看到核心人设、当前关系、本次召回的记忆、世界书条目、聊天记录数量和预算；页面上没有 API Key |
| 5.9 | 回复生成中点「停止」，再长按「重新生成」 | 停止后已写完的消息保留；重新生成正常 |
| 5.10 | 关闭识图时发一个没写含义的表情包 | 角色不描述图片画面（只能说「看不出来」之类） |

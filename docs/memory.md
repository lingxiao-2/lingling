# 长期记忆（V1 第二阶段 PR B）

在 PR #19 的 `memories` 表上继续开发：**没有新建数据库、没有升级 Dexie 版本**。新增字段（`worldId`、`mentions`、角色的 `memoryPrefs`）都是可选的，旧数据原样可用，备份 / 恢复照常包含它们。

## 记忆分类

| 类别 | 保存在哪里 | 发送方式 |
|---|---|---|
| 角色永久人设 | 角色资料（原文完整保存，不会为了压缩而修改） | 每次发送 |
| 与用户的固定关系 | 角色资料「你们的关系」 | 每次发送 |
| 共同经历 `event` / 长期偏好 `preference` / 重要约定 `promise` / 要记住的事 `user-fact` / 近期的事 `recent` | 记忆页（`memories` 表） | 按相关性检索 |
| 临时上下文 | 就是最近的聊天记录 | 最近 6000 字 |

新增记忆时按内容自动猜一个类别（`guessKind`），用户可以在编辑时修改。

## 自动记忆

1. **聊天中说「记住……」**：用户明确的要求，默认开启，可以在记忆页关闭。只保存用户自己的原话；敏感内容先放进「待确认」。
2. **定期提取**：**默认关闭**。用户在记忆页勾选后，会看到将发送什么、发送到哪个服务、会产生费用的说明，点「同意并开启」才生效。
   - 每新增 20 条用户消息，在一次回复完成之后，把这段时间（最多 40 条）的聊天发给**用户自己配置的 AI 服务**。不使用任何其他收费服务。
   - 候选必须引用**用户本人**的消息编号和逐字原文；引用角色消息的（AI 编的剧情）、找不到原文的一律丢弃。
   - 结果只进入「待确认」，用户确认后才会在聊天中使用。
   - 敏感内容（健康、财务、住址等）默认直接丢弃、不写入本机；用户另外允许后才作为待确认候选保存，7 天内不确认就清除。证件号、银行卡、密码、密钥任何情况下都不保存。
   - 失败时只在记忆页显示原因，并且要再聊 20 条才会重试，不会每次回复都重复请求。

## 去重与合并

- 相似度按相邻两字计算，标点和句尾语气词不同算同一句；**一句是否定、一句不是**（「喜欢香菜」/「不喜欢香菜」）不算重复。
- 再次说到已经记住的事：不新增，只把新消息作为依据合并进那条记忆（`sourceMessageIds`、`mentions`），**内容不改**。
- 「可能重复」：相似但不确定的两条列出来，由用户决定是否合并。合并时保留较完整的一句，或两句都保留，不改写意思。

## 检索（`recallMemories`）

全部在本机计算，不需要向量数据库，也不需要 Embedding API。

1. 固定 / 非常重要的（非敏感），最多约 500 字，每次都带。
2. 最近 3 天的共同经历和约定（最多 2 条）：新会话的第一句话也能接上最近发生的事。
3. 与当前话题相关的：关键词（相邻两字，去掉常见词）命中数 × 重要程度 + 时间相关性（越新越优先）；聊到「上次 / 还记得吗」时共同经历加分；已确立的关系中共同经历略微加分；敏感记忆需要命中更多关键词。
4. 只说了「还记得吗」、没有具体关键词时，带上最近的两条共同经历。

总字数不超过约 900 字。记忆页「检索试一试」使用同一个函数，可以看到一句话会召回哪些记忆以及原因。

## 隔离

- 按 `characterId` 读取，其他角色的记忆和聊天不会进入请求（自动提取也只发送当前角色的聊天）。
- 保存时记下角色所在的世界（`worldId`）。角色换到别的世界后，原世界线的记忆不再发送，在记忆页标记为「其他世界线」，可以手动改为当前世界。旧记忆没有这个字段，视为通用。
- 待确认、已删除、已失效（来源消息被删除）的记忆一律不发送。

## 测试

- `scripts/test-memory-recall.ts`：分类、否定去重、合并、检索排序、时间相关性、关系、世界线隔离、删除后不注入。
- `scripts/test-memory-auto.ts`：真实回复引擎 + IndexedDB + 模拟模型。反复说「记住」不累积、关闭后不保存、删除聊天后的新会话仍能召回、A / B 角色隔离、删除与合并即时生效、换世界、自动提取默认关闭、开启后 20 条触发一次且只进待确认、敏感内容默认不保存、失败不重复请求。

**未验证**：测试中的模型是模拟的。真实模型（如 DeepSeek）提取记忆的质量、是否稳定按 JSON 返回，需要在真机上验收。

## iPhone 验收步骤

| # | 操作 | 预期 |
|---|---|---|
| M1 | 聊天中发「记住，我不吃香菜」 | 记忆页「已记住」出现「我不吃香菜」，类别为长期偏好 |
| M2 | 再发两次「别忘了我不吃香菜哦」 | 仍然只有一条，显示「提到过 3 次」 |
| M3 | 记忆页添加一条约定并「固定」，然后在会话列表长按删除这个会话，重新进入聊天发「早」 | 「查看发送给 AI 的设定」中能看到这条约定；角色回复自然体现（不一定每次都提） |
| M4 | 另一个角色聊天时提到第一个角色的记忆内容 | 第二个角色不知道这件事 |
| M5 | 删除一条记忆后马上聊相关话题 | 「查看发送给 AI 的设定」中不再出现这条 |
| M6 | 记忆页勾选「定期从聊天中提取」 | 先出现费用和发送范围说明，点「同意并开启」后才生效 |
| M7 | 开启后再聊 20 条以上（其中说一些自己的喜好） | 记忆页「待确认」出现候选，并显示「自动提取：新增待确认 N 条」；**请截图告诉我结果**，用来验证 DeepSeek 的提取质量 |
| M8 | 「检索试一试」输入「还记得我们上次……」 | 列出会被召回的共同经历和原因 |
| M9 | 取消勾选自动提取 | 之后不再自动提取 |
